# Dataset guide

- knowledge_base/: five synthetic Markdown knowledge articles for RAG ingestion.
- tickets.json: fictional ticket records used by a local Python lookup function.
- routing_rules.json: supported intents and graph routes.
- conversation_scenarios.json: twelve end-to-end test scenarios.
- evaluation_dataset.json: input/reference pairs for LangSmith evaluation.
- escalation_policy.md: safe, simulated escalation rules.

All content is synthetic. Do not connect to a real ticketing system. Never invent ticket status, bypass approval or request credentials.
