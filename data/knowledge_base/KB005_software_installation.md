# Approved Software Installation

## Request process
1. Search the company's approved software catalogue.
2. Open the IT Service Portal and select **Software Request**.
3. Choose the software and provide business justification.
4. Submit for manager approval when required.
5. The software team checks licensing and compatibility.
6. IT installs or enables the software after required approvals.

## Important rules
- Employees must not install unapproved or unlicensed software.
- Local administrator privileges are restricted.
- A request may be declined if no licence is available or the software fails security review.

## Troubleshooting
If an approved installation fails, raise a Software Services ticket and include software name, version, device operating system and exact error message. Do not share licence keys or credentials.
