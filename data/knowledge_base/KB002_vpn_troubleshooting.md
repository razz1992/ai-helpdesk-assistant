# Corporate VPN Troubleshooting

## Basic checks
1. Confirm the device has an active internet connection.
2. Confirm the system date and time are correct.
3. Restart the VPN client.
4. Select the approved corporate VPN gateway.
5. Sign in using the corporate account and complete MFA.

## Common symptoms
- **Authentication failed:** Verify username, password and MFA method. If the account is locked, contact IT Support.
- **Connection times out:** Test internet connectivity and retry once. If it continues, raise a Network Access ticket.
- **VPN connects but internal sites do not load:** Disconnect and reconnect. If it persists, provide the affected internal site name to IT Support.

## Ticket information
Include device operating system, VPN client version, approximate failure time, exact error message and whether other internet sites work.

## Security
Do not send passwords, MFA codes or private keys in a support ticket.
