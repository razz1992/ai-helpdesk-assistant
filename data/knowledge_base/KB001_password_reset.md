# Corporate Password Reset

## Purpose
Instructions for resetting a forgotten corporate password.

## Standard procedure
1. Open the company's Identity Portal.
2. Select **Forgot Password**.
3. Enter the registered corporate email address.
4. Complete identity verification.
5. Follow the reset link or one-time code sent to the registered recovery channel.
6. Create a new password that meets the password policy.
7. Sign in again.

## Troubleshooting
- If the verification message does not arrive, check spam/junk and verify the registered recovery address.
- If the account is locked, do not repeatedly retry. Contact IT Support for an account unlock.
- If the Identity Portal is unavailable, raise an IT support ticket under **Account Management**.

## Security
IT Support will never ask an employee to disclose their current password or one-time verification code.
